# 심연의 다이스 포션

병을 흔들면 검푸른 액체 속에서 주사위 눈이 떠오르는, 크툴루의 부름 7판용 다이스 툴.
[나가곤 님의 실물 다이스 포션](https://x.com/nagagon1221/status/2088515756967567692)에서 출발했다.

**→ https://eincl.github.io/CthulhuDice/**

## 굴리는 법

| 환경 | 조작 |
| --- | --- |
| 휴대폰 | 기기를 직접 흔든다 (첫 탭에서 모션 센서 권한 허용) |
| 데스크톱 | 병을 잡고 흔들거나, `병 흔들기`를 길게 누르거나, `Space`를 누르고 있는다 |
| 어디서나 | 병을 한 번 탭해도 굴러간다 |

흔들면 액체가 탁해져 주사위가 사라지고, 손을 멈추면 침전이 시작되면서 액체 속의 눈이 떠서
당신을 보다가, 숫자가 천천히 떠오른다.

## 판정

1D100 모드에서 기능명과 기능치를 넣으면 CoC 7판 규칙으로 자동 판정한다.

- 1 → 대성공
- 기능치/5 이하 → 극단적 성공
- 기능치/2 이하 → 어려운 성공
- 기능치 이하 → 성공
- 100 (기능치 50 미만이면 96~100) → 대실패

다이스 모드는 1D100 / 1D10 / 1D6 / 1D8 / 1D4 / 1D3 / 1D20 / 2D6 / 3D6.

## 만듦새

의존성 없는 단일 HTML 파일. 파일 하나만 열면 어디서든 돌아간다.

- 눈은 `crypto.getRandomValues()`에 rejection sampling을 씌워 모듈로 편향 없이 뽑고,
  **흔들기가 시작되는 순간 확정**되어 애니메이션과 완전히 분리된다. 연출이 결과를 편향시키지 않는다.
- 액체·부유물·촉수·소환진·눈은 전부 Canvas 2D로 절차적으로 그린다.
- 흔들기 감지는 `DeviceMotionEvent`, 액면 기울기는 `deviceorientation`, 센서가 없으면 포인터 속도로 대체한다.
- 소리는 WebAudio로 합성한다. 오디오 파일이 없다.
